# Чеклист — метод чёрного ящика для приложения «Найди и иди»

## Поля ввода
- [ ] Валидные данные принимаются
- [ ] Данные ниже минимального значения отклоняются
- [ ] Данные выше максимального значения отклоняются
- [ ] Пустое поле обрабатывается корректно
- [ ] Плейсхолдер исчезает при вводе

## Кнопки
- [ ] Кнопка активна при выполнении условий
- [ ] Кнопка неактивна при невыполнении условий
- [ ] Нажатие даёт ожидаемый результат
- [ ] Внешний вид соответствует требованиям (текст, цвет, иконка)

## Сообщения об ошибках
- [ ] При невалидных данных появляется сообщение
- [ ] Текст сообщения понятен пользователю
- [ ] При успешном действии появляется подтверждение

## Навигация
- [ ] Все переходы между экранами работают
- [ ] Кнопка «Назад» возвращает на предыдущий экран
- [ ] Тупиков (экран без выхода) нет

## Граничные случаи
- [ ] Действие без интернета обрабатывается
- [ ] Повторное открытие приложения восстанавливает состояние
- [ ] Поведение при низком заряде батареи соответствует требованиям

## Область карты
- [ ] Маршрут из ответа сервера корректно отрисовывается на карте
