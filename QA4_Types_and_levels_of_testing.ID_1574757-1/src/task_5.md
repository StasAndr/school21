# Чеклист — метод серого ящика для приложения «Найди и иди»

## Поле ввода названия магазина
- [ ] При вводе 2+ символов в запросе поиска передаётся корректная строка (не обрезанная, без лишних пробелов)
- [ ] История предыдущих поисков корректно сохраняется и загружается из локального хранилища
- [ ] Спецсимволы (%, &, <, >) в названии магазина не ломают запрос

## Поле выбора типа магазина
- [ ] Выбранный тип магазина передаётся в запрос в корректном формате (например, строка или ID)
- [ ] При выборе типа магазина в запросе присутствует именно выбранное значение, а не плейсхолдер

## Кнопка «Поиск»
- [ ] При нажатии кнопки отправляется запрос с корректными параметрами (название и/или тип)
- [ ] Сервер возвращает статус 200 при успешном поиске
- [ ] Сервер возвращает корректный статус при отсутствии результатов (например, 200 с пустым массивом)
- [ ] Координаты флажков из ответа сервера совпадают с их позицией на карте

## Кнопка «Построить маршрут»
- [ ] При нажатии кнопки в запрос передаются координаты выбранного магазина и текущая геопозиция пользователя
- [ ] При выборе типа магазина в запрос передаётся тип, а не конкретный магазин
- [ ] Ответ сервера содержит данные маршрута в ожидаемом формате

## Область карты
- [ ] При отмене маршрута отправляется запрос на отмену (или состояние сбрасывается локально)

## Общие требования
- [ ] Незаконченный маршрут сохраняется в локальном хранилище при закрытии приложения
- [ ] При повторном открытии данные маршрута корректно загружаются из хранилища
- [ ] При низком заряде запрос на геопозицию переключается с точного на приближённый
- [ ] В логах фиксируется событие отключения точной геопозиции
- [ ] При отсутствии интернета в лог записывается ошибка сети, пользователю показывается понятное сообщение
