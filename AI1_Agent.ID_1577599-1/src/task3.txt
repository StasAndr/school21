 Какие ключевые элементы соблюдены?
- Четкая структура с разделами (ДОСТУПНЫЕ НАПРАВЛЕНИЯ, СТИЛЬ, ПЛАН)
- Явные запреты (НЕ переспрашивай, НЕ уточняй)
- Жесткие лимиты (РОВНО 6 вопросов)
- Конкретные примеры (C, Git, Linux)
- Шаблон ответа
- Усиление критичных элементов (вопрос про бассейн помечен ОБЯЗАТЕЛЬНЫЙ)

 Как они обеспечивают работу в workflow?
- Структура → модель не теряет фокус в длинном диалоге
- Запреты → нет зацикливаний на уточнениях (как было: "ты же уже знаешь мой возраст")
- Лимиты → предсказуемая длина диалога для автоматизации
- Примеры → консистентный уровень детализации ответов
- Шаблон → единообразный формат, легко парсить
- Усиление → гарантия выполнения критичных вопросов

 Почему эти элементы важны?
- Без структуры: бот уходит в "творчество", пишет сложно
- Без запретов: бесконечные переспрашивания, пользователь раздражен
- Без лимитов: опрос из 15 вопросов, пользователь уходит
- Без примеров: абстрактные ответы, непонятно что хотите узнать
- Без шаблона: каждый раз новый формат, хаос
- Без усиления: важные вопросы пропускаются
