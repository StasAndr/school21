# Граничные значения

Согласно технике граничных значений мы должны протестировать три значения, лежащих у каждой границы.
Граница - одна условная единица/ Граница / Граница + одна условная единица

# Граница 0
0) "0" не тестируем по условию.
0) Меньше "0" не можем задать по условию
1) "1000" провереям это значения, так как доступный шаг 1000
