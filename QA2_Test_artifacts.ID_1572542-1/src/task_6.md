# Тестовый сценарий для процессу ["Как поступить в школу 21"](https://21-school.ru/admission)

Название: 
Проверка страницы курса и подача заявки на поступление

Описание:
Пользователь переходит на страницу курса, изучает информацию о программе курса, просматривает часто задаваемые вопросы, затем заполняет и отправляет форму заявки. Проверяется корректность отображения всех элементов страницы и работоспособность формы подачи заявки.

Предусловия:
- Браузер открыт (Chrome/Firefox/Safari последней версии)
- Интернет-соединение стабильно
- Страница курса доступна по URL
- Пользователь ранее не подавал заявку на этот курс

Шаги:
- Открыть страницу курса
- Проверить загрузку всех элементов
- Просмотреть основные разделы (описание, программа, часто задаваемые вопросы)
- Заполнить форму заявки валидными данными
- Отправить форму

Ожидаемый результат:
Страница работает корректно, все элементы отображаются, форма успешно отправляется и приходит подтверждение.
